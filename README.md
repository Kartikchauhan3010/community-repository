# Kavix — Autonomous On-Device Mobile Scam Interceptor & Community Shield

Kavix is a privacy-first, zero-click mobile scam interception and community awareness platform.

## 🚀 Key Features
- **Zero-Click Background Interception**: Intercepts incoming SMS and app notifications (WhatsApp, PhonePe, Google Pay) using Android `NotificationListenerService`.
- **On-Device Risk Scoring**: Evaluates reverse-PIN traps, fake electricity cutoff threats, spoofed URLs, and fake KYC notices locally on the phone (100% privacy).
- **Multilingual Voice Alerts**: Plays immediate spoken warnings in Hindi and English using the Web Speech API (`hi-IN` & `en-US`).
- **1-Click 1930 Helpline**: Direct escalation to the National Cyber Crime Reporting Helpline.
- **GIS Heatmap**: Live Leaflet.js neighborhood sector incident map.
