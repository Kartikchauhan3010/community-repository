# CyberGuard & CommunityShield v2.0
## AI-Powered Community SDG & Cyber Crime Awareness Platform

An advanced, interactive full-stack web application designed for community SDG workshops and cyber safety awareness for senior citizens, small shopkeepers, and underserved households.

---

### 🌟 High-Impact Core Features

1. **🤖 AI-Powered "Scam & Phishing Message Analyzer"**:
   - Real-time heuristic pattern analysis & threat risk scoring (0-100%).
   - Detects suspicious links, urgent disconnection threats, and reverse UPI PIN traps.

2. **📱 Interactive "UPI & Soundbox Fraud Simulator"**:
   - In-browser interactive smartphone frame simulating fake payment screenshots vs. authentic soundbox audio chimes.

3. **🗺️ Live Local Incident GIS Heatmap & Analytics**:
   - **Leaflet.js** geographical tracking of community risk trends.
   - **Chart.js** dynamic threat category breakdown.

4. **🔊 Multilingual Voice Assistant (Web Speech API)**:
   - "Read Aloud / Suniye" speech synthesis for low-literacy accessibility in English & Hindi (`hi-IN`).

5. **📲 Emergency WhatsApp Alert Bot & Helpline 1930 Integration**:
   - Automated message alert dispatch and 2-hour emergency checklist.

6. **📊 Pre- & Post-Workshop Impact Metrics Engine**:
   - Quantifies participant confidence growth and awareness ratings for SDG reporting.

---

### 🚀 Quick Start Guide

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Seed Initial Database**:
   ```bash
   npm run seed
   ```

3. **Start Server**:
   ```bash
   npm start
   ```

4. **Open in Browser**:
   Navigate to `http://localhost:3000` or your Replit public URL.
